# STAT3007 generated-output example

This directory contains artifacts generated while testing `pre-review-notes` on the public
[STAT3007/STAT7007 course page](https://yenan.github.io/teach/stat3007/index.html).

It contains generated notes only:

- `notes/chapter-01-regression.tex` - English LaTeX source (source-only example);
- `notes/chapter-01-regression-zh.tex` - Chinese LaTeX source with canonical English terms;
- `notes/pdf/stat3007-regression-notes-zh.pdf` - compiled and visually checked Chinese output;
- `notes/progress.md` and `notes/topic-map.svg` - generated planning artifacts.

This chapter was generated and verified with v0.1.0 before the v0.2.0 capacity, token-ledger,
and active-learning gates. Its schema-2 state marks it as `legacy_generation`; the repository
does not invent retrospective usage or a context-fit result.

The 33 original slide PDFs are local test inputs, not repository examples. Their URL, byte,
page, and SHA-256 metadata lives in
[`tests/fixtures/stat3007/materials.csv`](../../tests/fixtures/stat3007/materials.csv). The
files themselves belong under the Git-ignored `test-data/stat3007/slides/` directory.

## Evidence boundary

Only lecture slides were available for this test. No grading breakdown, current exam format,
past paper set, marking guide, or official answer key was supplied. The notes therefore
demonstrate source-grounded lecture-note generation and do not claim an exam ranking or
assessment weight.
