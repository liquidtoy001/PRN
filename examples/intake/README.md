# v0.3.0 首次配置展示示例

这是 v0.3.0 的交互设计示例；当前处于发布准备阶段，已发布 v0.2.10 不含此流程。下列文件名和用户请求均为
演示设定，不代表已经读取资料、确认配置或生成笔记。实际使用时，Agent 应先沿用用户已说过的
选择，用真实材料范围替换示例，再一次展示完整配置；不能照抄这里的范围或确认状态。

保留两个入口：`pre-review-notes` 负责打印笔记，`pre-review-notes-html` 负责离线网页。
每个入口都有三套可修改的预设，不需要再安装三个用途不同的 Skill。

## 继续使用时

用户已经说“其余按推荐”时，展示上述已解决配置后直接继续，不再索要重复确认。否则等待
这次集中回复再生成。下次继续同一任务时读取保存值，只处理变化或缺失项。更换用途预设
保留已有自定义设置；明确要求重置预设默认值时，再集中展示变更。

上面验证的是交互设计的完整性，不是模型实际首次对话的测试结果。规则和运行时校验仍需
配合真实使用反馈，不能仅凭示例声称所有模型都会正确执行。
