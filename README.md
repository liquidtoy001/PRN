# Pre-Review Notes

**中文** | [English](./README.en.md)

把课程 slides、讲义和习题整理成可独立阅读的学习笔记。根据你的目标选择**课前预习、
知识巩固或考试复习**，再选择打印用的 PDF 或屏幕阅读用的 HTML。

这是给 AI Agent 使用的 Skill（任务说明和配套工具），需要配合支持 Skill、能读取文件的
Agent 使用。它本身不是双击就能运行的软件。

**当前版本：[v0.3.5](https://github.com/liquidtoy001/PRN/releases/tag/v0.3.5)。**
v0.3.5 会检查读者能否根据正文接着完成下一步。比如讲注意力时，笔记会先交代这道题里谁在查询、两个向量来自哪里，再展开一个点积，让你能接着算下一项。[本版改动](docs/releases/v0.3.5.md)

笔记默认采用适合打印的课程讲义版式：单栏正文、粗体分级标题、独立公式和浅灰表头。知识讲解连续排，题目按小问紧跟解析。HTML 沿用这套层次，可选折叠答案和深色阅读。

## 先选用途：三个预设怎么选

| 预设 | 你可能遇到的情况 | 笔记会怎样讲 | 建议提供的资料 |
|---|---|---|---|
| **课前预习** | 第一次接触这章；基础生疏；想先跟得上课 | 补必要前置知识，从具体问题和小例子引入概念，再串起本章内容与上课时值得留意的联系 | 即将学习的 slides、讲义或指定阅读 |
| **知识巩固** | 听过课但理解零散；会背公式却说不清原因；隔了一段时间想重新学透 | 讲清定义、机制、推导与适用条件，用例子连接相近概念，形成完整理解 | 已学章节的 slides、讲义、习题；也可说明自己卡在哪里 |
| **考试复习** | 想按考纲安排复习；需要把知识用到题目上；准备可独立阅读的复习总纲 | 根据实际考核依据组织知识，解释所选题目和小问，按题型处理作答表达 | 课件，加真卷、课程大纲或考点清单中的任意一种；有答案或评分标准也可提供 |

例如，同样学习“条件概率”：预习会先解释事件和“已知条件”的含义；知识巩固会连起条件概率、
联合概率及公式推导；考试复习会进一步对照所供题目，讲清如何读题、列式和解释结果。

**三个预设都保留选定范围内的细小知识点、条件、原例题和有用图表，并执行相同的覆盖与复核要求。**
预习会把前置知识讲在前面；时间不足时明确缩小范围，并列出尚未处理的内容。

默认设置与调整方式：

- **额外练习默认关闭。** 原课件例题、选定的往年题仍会解析。测验题、记忆卡或 HTML 折叠问答可以另行开启。
- **论文拓展：** 预习和考试默认关闭，知识巩固推荐附阅读清单，按确认的配置执行。
  如果只想使用课程资料，直接说“论文拓展关闭”。
- **正文代码、资料索引和生成过程说明默认关闭。** 实验原理仍需讲清；必要引用和图表署名保留，完整来源映射放在配套记录中。
- **已有选择优先。** 切换预设会保留你选过的语言、版式、练习等设置；希望恢复默认值时可以明确要求重置。

不确定选哪个，可以直接描述自己的情况。Agent 会推荐一个预设，并把其他选项一起列出来。
只有课件也能做考试复习笔记，但不能据此确定考试结构、题目频率或今年的重点。

## 决定做多少：范围与节奏

| 选择 | 适用场景 | 处理方式 |
|---|---|---|
| **先做一章**（lightweight，默认） | 第一次试用，或只需要一章 | 先完成指定文件或页码范围，保留充分讲解 |
| **分章完成课程**（full） | 想长期积累一整门课的笔记 | 先规划，再逐章生成并保存进度 |
| **限时冲刺**（exam-cram） | 有明确截止日期和可用学习时数 | 按资料依据和前置依赖安排顺序，明确范围取舍与待处理部分 |

学习用途和处理节奏可以自由搭配：考试复习可以提前几周分章完成，预习也可以只处理一小时内
计划学习的部分。选择考试复习后，仍可按正常节奏系统学习。

## 第一次使用：复制一个开场白

先把课程资料作为附件交给 Agent，或告诉它资料文件夹的位置。将示例中的文件名、章节和
页码替换成自己的实际范围；无需先理解内部配置名称。

**课前预习 · 打印阅读**

```text
使用 pre-review-notes，选择课前预习，中文，交付 PDF。
我第一次学这一章，先做 [文件名 / 第几章 / 页码范围]。
请补足需要的前置知识，用例子讲清概念，保留选定范围的细节和原例题。
请一次列出全部设置及推荐值让我确认。
```

**知识巩固 · 屏幕阅读**

```text
使用 pre-review-notes-html，选择知识巩固，中文。
先做 [文件名 / 第几章 / 页码范围]。我主要不理解 [概念或具体困惑]。
请讲清机制、推导与相近概念的联系，交付能离线打开的完整 HTML 文件夹。
请一次列出全部设置及推荐值让我确认。
```

想加 HTML 自测，可以在末尾补一句：“增加折叠问答，答案默认收起。”

**考试复习 · 按课程要求组织**

```text
使用 pre-review-notes，选择考试复习，中文讲解，交付 PDF。
根据我提供的考纲、考点清单或往年卷组织，先做 [章节 / 范围]。
补足解题所需的知识，解析对应题目，答题表达按材料中的考试要求处理。
请一次列出完整配置，其他设置按推荐值执行。
```

如果需要限时冲刺，再加上实际考试日期和可用学习时数。
英文作答表达会按题型和考试要求酌情提供；计算题与普通选择题默认使用笔记所选语言说明推理和结果，无需重复翻译。

## 首次配置会问什么

Agent 会一次显示当前入口的**全部设置、可选值和推荐值**，按四组整理：

1. **核心选择：** 用途、资料范围、笔记语言、交付成品。
2. **学习选项：** 处理节奏、讲解深度、论文、练习和时间。
3. **版式与展示：** 纸张或网页外观、疏密、代码、来源展示和自动复核。
4. **考试专项：** 组织依据与答题语言；其他用途也能看到这一组，并标为暂不适用。

高级选项也会完整显示。可以回复“用这个预设，其余按推荐”，或一次提出修改，
PDF 入口例如“论文关闭，改成 A5，其余按推荐”，HTML 入口例如“深色主题，增加折叠问答”。
如果开场时已经委托其余采用推荐值，Agent 展示
最终配置后就会继续。恢复旧任务时沿用已保存设置。查看 [完整配置示例](./examples/intake/README.md)。

## 生成之后会拿到什么

- **PDF 入口：** 请求的 PDF，以及选定的可编辑源文件。打开 PDF 检查公式、图表与分页后即可打印。
- **HTML 入口：** 保存完整文件夹，打开 `index.html`；图片等资源需一同保留。选择自测后可以展开答案。
- **配套记录与进度：** 保留来源映射、覆盖和复核记录，后续可以继续生成或修改章节。

初稿完成后，Agent 会提醒并继续逐知识点、逐题复核，再通读检查前置知识和讲解连贯性；
修正后重新构建并检查成品。若有待核实或未处理部分，会在交付时说明。
考试材料会先核对是否重复；统计题目出现频率时，同一试卷的副本只计一次，改编题和暂时无法确认的情况单独记录。

PDF 入口另有可选的题库、Anki 导出和重测工具；HTML 折叠问答目前不记录掌握度。

生成 PDF 需要 Agent 所在环境有可用的排版工具；如果缺少工具，Agent 应说明缺哪一步，
不能把源文件当作已完成的 PDF。你可以先让 Agent 检查环境，详见使用指南。
