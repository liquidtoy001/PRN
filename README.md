# Pre-Review Notes

**中文** | [English](./README.en.md)

把课程 slides、讲义和习题整理成可独立阅读的学习笔记，适合课前预习、知识巩固和考试复习。
保留细小知识点、例题与有用图表，中文笔记会保留重要术语的英文名称。来源映射默认放在配套记录中。

这是给 AI Agent 使用的 Skill（任务说明和配套工具），需要配合支持 Skill、能读取文件的
Agent 使用。它本身不是双击就能运行的软件。

**版本状态：v0.3.0 正在准备发布。** 本页描述 v0.3.0；GitHub 当前已发布版本仍为
[v0.2.10](https://github.com/liquidtoy001/PRN/releases/tag/v0.2.10)，该旧包不包含本次新流程。

## 第一次用，从这里开始

1. **选一个版本。** 想打印、手写批注，选 PDF 版；想在屏幕上阅读、展开自测答案，选 HTML 版。
2. **下载并安装。** 打开 [最新 Release](https://github.com/liquidtoy001/PRN/releases/latest)，
   在 Assets 中选择下表里的 ZIP。安装方法见 [小白使用指南](./USAGE.md)。
3. **准备资料。** 把需要处理的 slides 或讲义交给 Agent，先选一章试用。
4. **复制下面的开场白。** Agent 会一次显示全部设置和推荐值，你可以一句话接受或集中修改。

| 你想要什么 | 下载哪个文件 | 调用名称 |
|---|---|---|
| 打印笔记、PDF，也可选 Markdown / LaTeX | pre-review-notes-v0.3.0.zip（待发布） | pre-review-notes |
| 离线网页笔记、可选折叠问答 | pre-review-notes-html-v0.3.0.zip（待发布） | pre-review-notes-html |

不确定时先选 PDF 版。两个包可以分别安装，也可以同时安装。下载 Assets 里的安装 ZIP，
不需要下载 GitHub 自动提供的 Source code。旁边的 `.sha256` 是校验文件，不能用来安装。

**PDF 版开场白：**

```text
使用 pre-review-notes，帮我把这些课程资料整理成中文学习笔记。
选择知识巩固版，先做第 1 章，最后给我 PDF。
请保留细小知识点，解释公式和有用的图表。
其他配置请一次列出来让我选。
```

**HTML 版开场白：**

```text
使用 pre-review-notes-html，帮我把这些课程资料整理成中文网页笔记。
选择知识巩固版，先做第 1 章。
正文保留完整讲解，另外加可折叠答案的自测题。
请交付能离线打开的整个文件夹，其他配置请一次列出来让我选。
```

把“第 1 章”换成你要处理的文件名或页码。“先做一章”（lightweight）的意思是先做一小批，
同一范围内仍应充分讲解。知识巩固版默认不出新题；上面的 HTML 示例明确选择了自测。

## 三个预设，所有设置一次看全

| 预设 | 适合你想做的事 | 默认论文拓展 | 默认额外练习 |
|---|---|---|---|
| 课前预习 | 补前置知识，用例子建立直觉，跟上课堂 | 关闭 | 无 |
| 知识巩固 | 讲透定义、机制、推导和相近概念 | 推荐阅读 | 无 |
| 考试复习 | 根据真卷、大纲或考点组织讲解与解析 | 关闭 | 无 |

预设决定讲解路线，“先做一章 / 分章完成课程 / 限时冲刺”决定范围和节奏。
首次对话按核心选择、学习选项、版式展示、考试专项四组列出**全部可选值和当前推荐**，
包括高级和暂不适用的选项。可以回复“用预习预设，其余按推荐”，不必逐项填写。
已有选择会保留，额外练习、论文和代码都能单独调整。看 [完整配置示例](./examples/intake/README.md)。

## 它会怎样处理资料

- 登记选定页面和知识点，保留条件、推导、原有例题和有教学价值的图表。
- 补足实际用到的前置知识，把相近概念和推导连起来，默认不展示正文代码。
- 保存来源页码和知识映射；资料索引、来源过程说明默认放在配套记录，必要署名保留。
- 考试用途先核对真卷、大纲或考点；重复卷不重复计频，计算与普通选择题不机械附英文答案。
- 初稿完成后提醒并继续逐知识点、逐题复核，再通读检查连贯性；有遗漏就修正和重建。
- PDF 版要求检查分页和图表布局；HTML 版要求检查阅读、公式、图表和折叠交互。
- 分章保存进度，后续可以继续。PDF 版还提供可选的题库、Anki 导出和重测工具；
  HTML 版的折叠问答目前不记录掌握度。

生成 PDF 需要 Agent 所在环境有可用的排版工具；如果缺少工具，Agent 应说明缺哪一步，
不能把源文件当作已完成的 PDF。你可以先让 Agent 检查环境，详见使用指南。

## 示例与当前限制

[自编 HTML 样本](./tests/fixtures/html/) 用于检查公式、图片和问答结构；
[早期课程笔记示例](./examples/stat3007/README.md) 是历史试验，不代表当前版本的效果保证。

实际课程试用主要集中在 AI / 机器学习。跨学科准确性和学习效果尚未经过系统评测。
工程检查和实际页面检查的执行范围见 [v0.3.0 验证记录](./TESTING-0.3.0.md)。
自动化测试不证明教学效果或内容无误，实际使用时仍需对照原始资料检查。

课程 slides 和个人资料应保存在本地，不要提交到本仓库。
原始第三方课件不随安装包分发；代码和原创模板使用 [MIT License](./LICENSE)，
该授权不覆盖第三方课程材料。
