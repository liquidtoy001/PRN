# Screen-note depth diagnostic

An HTML page has no stable printed-page count. Do not apply the print entry's page threshold
to viewport height or browser print pages. Judge completeness against every distinct K ID,
including small conditions, source examples, diagrams and derivations. A long scrollbar,
large font, repeated prose or hundreds of collapsed questions cannot establish teaching depth.
Collapsed self-test answers do not substitute for visible teaching sections. Explain unusually
short results using inspected animation/duplicate groups and actual coverage evidence.
